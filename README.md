# README - Caesar Cipher Project

## Caesar Cipher Implementation Using Python

### Project Description

This project implements the Caesar Cipher algorithm using Python. The program can encrypt and decrypt text by shifting the letters of the alphabet by a user-defined value.

The user enters a message and a shift value. The program then performs encryption or decryption based on the user's choice.

### Objectives

* To understand the Caesar Cipher algorithm.
* To implement encryption and decryption using Python.
* To perform secure text transformation using a shift value.
* To develop a simple command-line application.

### Technologies Used

* Python 3
* Visual Studio Code
* Git
* GitHub

### Features

* Encrypts text using a shift value.
* Decrypts encrypted text.
* Supports uppercase and lowercase letters.
* Preserves spaces and special characters.
* Provides a simple user interface through the terminal.
